New: Linux

- The launcher now runs on Linux as a single AppImage, `VCS-Recomp-0.2.0-x86_64.AppImage`. It works on Ubuntu 22.04, Debian 12, Linux Mint 21 and newer, on X11 or Wayland. It needs a Vulkan driver (Mesa or NVIDIA).
- Make it executable and start it. It walks you through the same steps as on Windows, and installs the packages the build needs (it asks for your password). On Ubuntu 22.04 and Debian 12 it first adds LLVM's own repository, because their clang is too old for the game.
- The game is built in `~/.local/share/VCSRecomp/install`. It uses the same saves as a build from a git clone.
- Prefer the command line? You can still build without the launcher: clone the repository and follow *Install by hand* in the README (`python3 tools/build.py --recompile`).

Also

- Performance improvements targeting Linux.

Updating: on Windows, go to Settings → Updates → Update now in the launcher, restart it, then update the build. Your saves aren't touched. You can also extract the zip into a new folder. On Linux, download the AppImage; later updates replace it from Settings in the same way.
